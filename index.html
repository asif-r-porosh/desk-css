Use it

Copy desk.min.css from dist/ next to the page and link it. Icons and fonts are optional and load from the fonts/ folder next to the CSS.

<link rel="stylesheet" href="desk.min.css">
<link rel="stylesheet" href="desk.icons.min.css">  <!-- optional -->

For coding agents, DESK.md is a plain-text guide and check.py checks a finished page against the real CSS.
