desk.css

A lean CSS library for everyday tools. Plain HTML looks right with no classes; a short list of classes covers the rest. Sized for laptops, works on phones, no JavaScript needed.

Install

Copy desk.min.css, desk.icons.min.css (optional) and the fonts/ folder from dist/ into the project, side by side. The readable desk.css and desk.icons.css in the same folder are identical apart from comments and whitespace.

Minimal page

Everything in desk.css sits in a cascade layer called desk. Any CSS written outside a layer wins over it automatically, so overrides never need !important.

Page settings

Three attributes on <html> control the whole page. Leave one out to get its default. The buttons in the top bar change them on this page.

AttributeValuesDefault
data-themelight, darkFollows the system setting
data-densitynormal, compactnormal: 16px text, 40px controls. compact: 14px text, 32px controls.
data-accentgreen, teal, purple or orangeBlue

Any accent color works without a preset. Set it once; links, primary buttons, focus rings, checkboxes, switches, sliders, progress bars, active tabs and tints follow. Button text turns black or white to suit the color.

󰋼
Status colors (ok, warn, danger, info) and the greys never follow the accent, so a failed item never looks like a healthy one.

App shell

This page is built with it. Above 768px the sidebar sits beside the content and stays in view while the page scrolls. Below it, the sidebar turns into a drawer behind the menu button; it closes on an outside tap or Escape.

Sections inside main get spacing and a divider. .wide-only and .narrow-only show or hide anything at the same 768px breakpoint.

Icons

Load desk.icons.css, then put the character code into any text. The icon follows the text's size and color; no extra tags or classes.

Rules and limits

Browser support

Target: the latest stable release of Chrome, Edge, Firefox and Safari. Tested: Chromium 153 (the engine behind Chrome and Edge). Firefox and Safari are not tested yet.

  • The stylesheet needs Chrome or Edge 125, Firefox 128, Safari 18. These versions set the floor through light-dark() and relative colors; :has(), cascade layers, popover and color-mix() are older.
  • Opening dialogs with commandfor needs Chrome or Edge 135, Firefox 144, Safari 26.2. Older browsers ignore those buttons; showModal() in script still works.
  • Small details fall back quietly: accent-color before Safari 26.2, scrollbar-width before Safari 18.2, text-wrap: balance, and contrast-color() (button text is white without it).

Deliberately left out

  • A 12-column grid. .grid and .cols-N cover real layouts without breakpoint classes.
  • Spacing utilities for every side and size. Layouts use gap; components carry their own spacing.
  • JavaScript components. Dialogs, drawers, dropdowns and accordions use native HTML; a few lines of script add extras such as toasts or closing a dropdown on outside click.
  • Fonts beyond Latin. Other scripts fall back to the system font.

How overrides work

The library lives in @layer desk. Project CSS written outside a layer always wins. Change a token on :root to restyle everything that uses it; target a class to change one component.
